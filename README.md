# CoreVac Website

Static website for CoreVac.

## Local preview
Open `index.html` in a browser.

## GitHub Pages
Repository: `Corevac-website`
Branch: `main`

After uploading these files:
1. Open Settings → Pages.
2. Under Build and deployment choose **Deploy from a branch**.
3. Select `main` and `/ (root)`.
4. Save.
5. Add the custom domain `corevac.in`.

Do not change the GoDaddy DNS records until GitHub Pages is enabled and the custom-domain instructions are visible in GitHub.
